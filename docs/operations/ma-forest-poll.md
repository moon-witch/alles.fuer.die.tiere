# MA-Forest: observe-only source poll

The [official MA-Forest page](https://en.wilderness-international.org/ma) renders placeholder numbers in its initial HTML and replaces them in the browser with data from its first-party [campaign statistics endpoint](https://en.wilderness-international.org/api/statistics/v1/campaigns/independent?ids=80718821-5f98-4802-a61c-d6398933d8b8). This mechanism was checked on 6 October 2026. The adapter is deliberately narrow: campaign UUID `80718821-5f98-4802-a61c-d6398933d8b8`, code `MA`, protected area in m², donation count, protected kg CO₂, the campaign section, its goal, and its donation destination. It never treats the HTML placeholders as observations. The endpoint is first-party and publicly used by the page, but has no stability guarantee; a changed shape pauses polling for review.

Polling is **off by default**. Set `MA_FOREST_POLL_ENABLED=true` as a runtime variable on the **worker only** after the worker can reach the public HTTPS page and its private `raw` S3 bucket. The first poll creates or updates the private source registry entry, stores the official JSON response and campaign page as compressed raw snapshots, and opens a review item. It does not create a public metric, edit a publication, or change the donation destination shown on the website. The source detail page linked from `/admin/quellen` shows the latest observed value and the last 150 runs; compare it with the live page during the 30-day observe-only period required by the ingestion plan.

The worker schedules one poll every six hours. It sends the previous JSON ETag for conditional GET; HTTP 304 reuses the previous verified statistics while still checking the campaign page and donation destination. A small increase or downward correction is recorded for review, not treated as a failure. A movement over 20%, changed goal, or changed destination receives a warning. The worker makes one retry after 15 minutes for a transient failed cycle; a second failure opens a review item and returns to the six-hour cadence. HTTP 403/429, malformed data, a missing campaign section, or an unsafe destination pauses the source immediately. In `/admin/quellen/[id]`, a steward can resume a paused source only with a recorded review note. Resolving an attention item alone does not resume polling.

Keep this adapter observe-only for at least 30 days. Any later change allowing automatic public metric updates requires a separate reviewed implementation and explicit field approval. The destination URL always requires human confirmation.

For an isolated integration check, apply migrations to a disposable PostgreSQL database and run `npm run test:ma-forest-db`; the script creates jobs, source rows, snapshots, and review items. Never run it against production.
